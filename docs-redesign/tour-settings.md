# Settings

<p class="lede">The settings that belong to you rather than to a font: shortcuts, theme, language, what Copy puts on the clipboard, and how far the arrow keys move a point. Two minutes.</p>

<div class="pill-row">
<span class="pill">2 minutes</span>
<span class="pill">Beginner</span>
<span class="pill">Tour</span>
</div>

<h2 id="open">Opening the settings</h2>

The first menu of the menu bar, **Fontra**, lists the settings panels: choose one and the settings page opens at that panel, in a window of its own. The settings are kept by your browser, for this computer.

<h2 id="shortcuts">Shortcuts</h2>

<div class="video"><div class="play"></div><div class="cap">click a shortcut, press new keys</div></div>

Every action with its shortcut, grouped by topic: Tools, Edit, View, Glyph, Sidebars… **Click a shortcut and press the keys** you want instead; if they are taken, Fontra says by what. While a shortcut is selected, the two icons beside it reset it to its default or clear it.

Actions without a shortcut — the path operations, the alignments, the display layers — can be given one here. **Export shortcuts** saves your changes to a `.json` file, **Import shortcuts** loads one: the way to take your set to another computer, or share it. **Reset all shortcuts** goes back to the defaults.

<h2 id="theme">Theme settings</h2>

**Automatic** follows your system's light or dark mode; **Light** and **Dark** fix it.

<h2 id="language">Display Language</h2>

The language of Fontra's menus and panels. Languages whose translation is not finished are marked *beta* or *work in progress*; the page links to the spreadsheet where anyone can help translate.

<h2 id="clipboard">Clipboard</h2>

What **Copy** puts on the clipboard as text, for pasting into another application: **GLIF** (RoboFont's format, the default), **SVG**, or **JSON** (Fontra's own). Copying and pasting inside Fontra works whatever you choose.

<h2 id="editor-behavior">Editor Behavior</h2>

- **Arrow key nudge values**: how far the arrow keys move a selection — 1 unit by default, 10 with <kbd>⇧</kbd>, 100 with <kbd>⇧</kbd><kbd>⌘</kbd>.
- **Use live modifier keys for rectangle-select**: when on, the modifier keys you press *during* a selection drag count, not only those held when it started.

<h2 id="others">Plugin Manager and Server info</h2>

**Plugin Manager** adds editor plug-ins, by GitHub repository (`owner/repo`) or by address. **Server info** shows the versions of Fontra and Python you are running, and the file formats the server opens — useful in a bug report.
