## What is Fontra, in one minute

Fontra is a font editor with two parts: a **client** that runs in your web browser, and a **server** that runs on your own machine (via Fontra Pak) or on a remote host. The browser is just the interface: your files stay with you, and you can work fully offline. Put the server on a network and several people can edit the same font in real time.

It is **variable-first**: multiple sources, live interpolation, and variable components are foundations, not add-ons. If you have only ever made static fonts, [Your first variable font](/tutorials/your-first-variable-font/) is the fastest way to feel the difference. The [Introduction](/introduction/) says more about where Fontra comes from.

## Tutorials inside the editor

The [Fontra Tutorials](https://github.com/Uplus-Type/fontra-tutorials) plug-in puts guided tours and hands-on lessons in Fontra itself: a bubble on each thing to look at or click. Add the address `uplus-type/fontra-tutorials` under *Fontra › Plugin manager* (see [Plugin manager](/reference/menu/fontra/plugin-manager)), reload the editor, and open the **Tutorials** panel: Around the editor, Your first font, Font info and designspace, the Font overview, Coming from Glyphs, Coming from RoboFont. The same tours are built into [Try Fontra](/get-started/try-online/).
